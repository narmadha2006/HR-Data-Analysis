# HR Analytics – Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on performing an in-depth *Exploratory Data Analysis (EDA)* on an HR dataset to uncover actionable insights about employees, departments, job roles, and compensation. The goal is to support HR decision-making with data-driven insights.

## 🎯 Objectives
- Clean and preprocess HR data for analysis.
- Identify patterns in employee hiring, working modes, and departmental distribution.
- Explore salary variations across departments, job titles, and experience levels.
- Analyze performance ratings by department.
- Detect outliers and understand key correlations within the dataset.

## 📂 Steps in the Notebook
1. *Data Loading & Initial Inspection* – Import libraries and load the dataset.
2. *Data Preprocessing* – Handle missing values, data types, and inconsistencies.
3. *Data Cleaning* – Ensure the dataset is ready for analysis.
4. *Outlier Detection* – Identify and handle extreme values.
5. *Univariate Analysis* – Explore individual features like department size, working mode, salary distribution.
6. *Bivariate Analysis* – Compare metrics such as salary vs. experience and performance rating by department.
7. *Correlation Analysis* – Visualize relationships among variables.

## 🔑 Key Insights (Examples)
- Which department has the most job vacancies.
- Most common employee working mode.
- Departments with higher average salaries.
- Salary trends based on years of experience.
- Departments with the highest/lowest performance ratings.
